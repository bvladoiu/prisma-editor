# Prisma Editor (Work in Progress)

A Kotlin Multiplatform project for editing static content.

## Project Structure

- `src/jsMain`: JavaScript/Web frontend
- `src/jvmMain`: JVM/Desktop application

## Development

### Prerequisites

- JDK 11 or higher
- Gradle

### Building

```bash
./gradlew build
```

### Running

#### Web Application

```bash
./gradlew jsBrowserDevelopmentRun
```

#### Desktop Application

```bash
./gradlew jvmRun
```
